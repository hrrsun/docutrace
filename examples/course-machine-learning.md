# 机器学习复习笔记

课程：机器学习。学期：大二下。此文件为项目自编合成演示资料。

## 优化与梯度下降

训练时优化模型参数以降低损失函数。批量梯度下降使用全部训练数据估计梯度，随机梯度下降使用单个样本，小批量方法使用一批样本。参数更新为 θ_new=θ-η∇L(θ)，其中 η 为学习率。其数学基础是多元微积分中的梯度。

学习率过大可能振荡，过小可能收敛缓慢。非凸损失下不保证找到全局最小值。评价模型时必须区分训练损失和未见数据上的泛化效果。

## 过拟合和正则化

模型在训练集表现好、在验证集表现差是过拟合的典型迹象。L2 正则化在目标中加入参数平方和惩罚；L1 正则化加入绝对值和惩罚，常有稀疏化效果。验证集用于选超参数，测试集用于最终评估。

## 复习检查

说明负梯度方向与参数更新的关系；用 x² 举例计算一次更新；说明为什么训练损失下降并不代表泛化一定改善；比较 L1 和 L2。
